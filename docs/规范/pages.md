# 页面内容与操作说明

## 核对依据

本次按工程规则以及[易语言官方操作手册](https://www.dywt.com.cn/help/opr.htm)的工作夹、状态夹、程序编辑与窗口设计组织方式核对 PCIDE 页面。参考资料用于安排导航、帮助和属性交互；PCIDE 仍使用自己的源码、工程格式和运行时。

页面显示跟随当前工程的开发模式。“视图”菜单提供所有适用页面的入口；关闭中央标签后，可以从此菜单恢复。文件、子程序、断点与调用位置导航也会恢复代码页。

本次复核补齐统一“提示”页、实际窗口菜单编辑器、完整排列入口和回车导航，共核对 14 个主页面/目录。

## 本次复核补齐的操作

- “设计 → 排列”提供左右上下对齐、水平/垂直中心对齐、等宽/等高/等大、水平/垂直等间距、父容器居中及顶层/底层顺序；控件右键共享相同动作。按同一父容器分组，对齐以工程顺序中的首个选中控件为参照，等间距至少需要三个控件。
- 设计画布提供选择全部、复制和粘贴；快捷键只作用于设计画布。容器子控件使用真实父级坐标，复制容器保留子控件相对位置；删除父容器并保留子控件时，其画布位置保持不变。
- 窗口菜单保存真实定义并参与运行。菜单项可绑定独立处理子程序，也可使用菜单栏单击处理器；事件参数包括菜单栏 id、menu_id、text 与 checked。最多 256 项、8 层，拒绝重复标识、重复快捷键和不支持的字段/类型。旧 items 顶层名称保持兼容；层级菜单使用专门编辑器，避免两个入口修改不同数据。
- 单纯预览显示当前设计中的未保存内容，并忽略脚本事件；F5/F4 执行模式才分发事件。菜单事件按钮可创建或进入子程序，随后正常保存源码和窗口定义。
- 调试调用表和断点表支持双击或回车跳转；调用位置须在当前工程内。底部输出增加清空和导出日志，中央与底部仍共用一份文档。

## 合并和删减记录

- 资源表、外部文件记录表合并为实际资源页，变量/常量使用统一程序数据分类。
- 新建源码文件移至项目菜单；平台菜单重复的 Unity 接入入口移除，引擎菜单保留。
- 中央和底部输出共用日志；入口子程序不在源文件和独立列表中重复显示。
- 项目环境移除运行器不会读取的语言转换/解释器字段，改为真实执行入口与运行限制。
- 非脚本工程隐藏脚本页面；非窗口工程隐藏窗口页面、窗口导航和控件箱。
- 控件未连接的事件不提供新增入口；旧工程保存的该事件绑定保留为禁用项，避免静默丢失。

## 当前实际边界

- 易语言 EC/FNE 可登记，官方编译或专用 ABI 桥接尚未实现；窗口菜单使用 PCIDE 自己的明确表单格式，未宣称易语言全部语法、程序集或二进制兼容。
- 时钟目前只有设计属性，尚无定时事件；网页组件显示地址/文本，尚无浏览器页面加载与交互。
- 调试变量是暂停时的只读快照；断点变更用于下一次调试启动。未实现运行中修改变量或实时更新断点。
- 流程最长运行 30 秒；模拟截图/OCR/YOLO 只用于流程检查。框选标注使用类别 0，导入标签保留其原类别。真实识别、训练、设备及 GPU 效果另行验收。
- 数据库页目前使用 SQLite 合同和 CRUD SQL/元数据，不宣称完整 ORM 或其他数据库提供者。
- API HTTP/HTTPS 可生成实际客户端，HEAD/OPTIONS 与当前传输一致；Python/中文客户端网络超时上限 60 秒，JS/TS 用 AbortController 按配置取消请求。WebSocket/TCP/UDP/MQTT 只保存声明，需要外部 transport。响应类型目前是声明，客户端仍使用原有自动解析。
- 资源页不执行 DLL/EXE；文本预览前 64 KiB，图像源文件最多 16 MiB/1600 万像素，列表最多 10000 个文件。
- 平台开关和提供者声明不会自动安装或实现能力；系统工具和引擎入口使用已安装环境。模块运行中热替换、Node 版本模块表、高级 DLL ABI、Android 真机和干净机器部署仍有既有边界。

本轮测试和冻结交付的具体结果记录在 `docs/archive/verification.md` 最新节；此前硬件、视觉和客户发布证据单独保留。
