# Plugin Contract v1

- Manifest: stable ID, semantic version, API version 1, architecture, kind, relative entry, declared capabilities, granted permissions, exact dependency versions, lifecycle.
- Registry rejects duplicate IDs, malformed JSON, path escape/symlinks, missing dependencies, unsupported architecture/API and permissions not granted by the project.
- At most four loaded hosts. Each host owns one serialized bounded request stream; request/response IDs are matched. Timeout/disconnection/crash closes the host; explicit load creates a new process. Duplicate live load is idempotent.
- Permissions limit registered capabilities and host routing. These processes run under the current Windows account; process separation provides crash containment, not an OS sandbox for malicious code.
- C ABI uses `pcide_abi_version()->uint32`, `pcide_init()->int`, `pcide_call(const char*)->const char*`, `pcide_shutdown()->void`. Caller copies UTF-8 JSON (max 64 KiB); response buffer remains plugin-owned until the next call. DLL exports are resolved via ctypes LoadLibraryEx/GetProcAddress in the child host. Shutdown is followed by process exit; no forced native hot unload.
- Python/pyd requires matching CPython ABI and `plugin_entry(request)`. Standard output is redirected to the host log. A pyd is imported only in its host process.
- .NET requires `public static string Call(string json)`. A collectible `AssemblyLoadContext` plus `AssemblyDependencyResolver` resolves managed/native dependencies in a separate .NET host. Unload requests release references and exit the host.
- DEX manifest routes only to the Android remote host. DEX is browsed on PC and executed by ART/DexClassLoader on Android. Missing host/connection/permissions returns failure; no Windows DLL fallback.
- Examples: `examples/plugins/mock_vision`, `native_math`, `dotnet_math`. Sources: `src/hosts`. Build products are generated by `tools/build_hosts.py`; compiler/SDK are kept under `sdk`, temporary obj under `cache/build`.
