# 支持库、模块与数据表

## 入口与使用顺序

1. 左侧 **支持库 → 加入**，或 **扩展 → 加入支持库/模块**。
2. 选文件，填写代码名称与 `major.minor.patch` 版本；按文件格式填写公开接口、DLL ABI 或 Android 连接。
3. 点击 **加入项目并生成调用示例**。复制示例，或在左侧双击命令插入代码，填写参数后运行。
4. **支持库 → 配置** 保存本项目显示的系统库；封装库未授权时状态列显示缺少的权限，选中后可明确授权。
5. **支持库 → 帮助** 给出所有格式的封装方式和官方参考资料。

支持库夹按命令分类、库定义数据类型、库定义常量展示。项目变量、常量、自定义类型、DLL 声明位于程序夹的数据表；系统目录中的命令使用当前运行语言的真实 API。系统目录配置控制目录和补全，不禁用语言自身的内置函数。

## 中文源码项目的易语言式支持库目录

中文源码（`.zhxb`）项目的左侧支持库按易语言核心库的分类方式展示实际已实现的 **流程控制、算术运算、逻辑比较、位运算、变量操作、数组操作、环境存取、文本操作、字节集操作、数值转换、时间操作、磁盘操作、文件读写、系统处理、程序调试、其他、数据库、网络通信、控制台操作**，另有 PCIDE 的数据转换和线程任务接口。窗口支持库列出窗口及当前控件箱的 27 类组件，每个组件可展开查看属性的代码名称、类型、默认值、可选值、事件和代理方法。选中任意条目后，下方立即显示说明、返回信息和实际代码示例。

命令名称是目录标题，实际调用以显示的源码示例为准；双击插入当前语言 API 或中文源码语句。数据库、网络和窗口项目使用 `pcide.runtime_api` 的代理。C、C++、C#、Unity 和网页的示例移至左侧独立的 **代码片段** 页，并保留右键帮助、双击和拖放。C/C++/C#/HTML 等文件显示并保存原文，中文子程序视图按钮按当前文件语言启用。

本目录提供 PCIDE 的实现，未实现的易语言拼音、媒体、COM 类型和专用组件没有列为可执行接口。时钟目前只有设计属性与显示组件，网页组件目前只显示地址/文本，详细说明中明确列出这些边界。PCIDE 尚无完整易语言命令实现、EC 编译器和 FNE ABI 宿主。

### 窗口菜单与提示

选择命令或片段后，可从“视图 → 当前操作提示”（Ctrl+Alt+H）查看完整说明及调用示例。提示与输出在下方分成两个标签，输出可清空或导出。

“设计 → 窗口菜单编辑器”（Ctrl+Alt+M）与菜单栏属性页共用同一编辑器，保存下级菜单、分隔线、唯一标识、快捷键、启用/可见/勾选及处理子程序。点击“创建 / 打开处理子程序”可进入真实事件代码。菜单项独立绑定优先；未设置时使用菜单栏单击处理器。参数含菜单栏 id、menu_id、text、checked，event 为 menu。

菜单定义位于 MenuBar 控件的 properties.menu，示例：

```json
[
  {"id": "file", "kind": "menu", "text": "文件", "children": [
    {"id": "open", "kind": "item", "text": "打开", "shortcut": "Ctrl+O", "handler": "on_open"},
    {"id": "separator", "kind": "separator"},
    {"id": "show", "kind": "item", "text": "显示信息", "checkable": true, "checked": true}
  ]}
]
```

菜单最多 256 项、8 层，标识与快捷键不得重复；处理器必须为有效子程序名称。旧 items 顶层名称仍可读取，menu 存在时以层级定义为准。单纯预览显示当前未保存的设计且不执行处理器，F5/F4 运行才分发事件。

## 文件格式合同

| 格式 | 加入与调用 | 当前边界 |
| --- | --- | --- |
| `.py` / `.zhxb` | 复制到 `src`，选择顶层公开函数；在模块引用表维护接口、版本、依赖；`模块.函数(参数)` | 仅 Python/中文运行时；修改源码后下次运行重新加载 |
| `.js` / `.ts` | 语法检查后复制到 `src`；`require("./模块").函数(参数)` | 仅 Node 运行时；路径相对调用文件；Node 模块不使用 Python 精确依赖表 |
| 普通 `.dll` | 复制到 `resources/libraries`，填写实际导出、参数 ABI、返回 ABI、调用约定，创建 DLL 命令声明 | 独立宿主、匹配位数；标量及 UTF8/UTF16 文本输入；指针、结构体、输出参数、文本返回未开放 |
| `.pcplugin` / `.zip` / `plugin.json` | 包根清单与入口/依赖一起复制到 `plugins/<id>`；`plugins.call(id, capability, params, timeout=5)` | `json-v1`，Python cp312；声明依赖须已安装且版本精确匹配；每调用关闭独立宿主，不保留状态 |
| `.ec` | 保存到资源并显示“待桥接封装”；用易语言引用并编译成明确 ABI 的 DLL 或供应方桥接包，再加入 | PCIDE 没有 EC 编译器；登记不代表能直接执行 |
| `.fne` | 保存到资源并显示“待桥接封装”；需要易语言支持库 ABI 宿主或供应方协议封装 | FNE 是专用支持库，不能按普通 DLL 直接调用；专用宿主尚未实现 |
| `.dex` | 校验 DEX 并索引类名；填写桥接地址、Android 宿主内相对路径和完整类名；插入 `dex.call` 示例 | 文件须先部署到 Android；类需公开静态 `String call(String)`；不自动上传，真机尚未验收 |
| `.pyd` / .NET DLL | 用 `plugin.json` 包装，选择 `python` / `dotnet` 宿主 | PYD ABI/位数匹配；.NET 为公开静态 `string Call(string)` JSON 协议，不能按普通 DLL 处理 |

复制导入文件不覆盖现有文件。源码导入会检查语法与公开接口；不在 IDE 中执行第三方代码。封装包有 SHA256、路径、重复成员、文件数和体积门禁。库清单为 `.pcide/libraries.json`，保存版本、来源摘要与状态；摘要记录加入时的内容，源码仍可正常编辑。写入参考表失败时恢复先前表，复制文件保留用于诊断。

## Python 封装示例

包根 `plugin.json`：

```json
{"id":"sample.math","name":"算术库","version":"1.0.0","kind":"python","entry":"entry.py","capabilities":["add"],"permissions":[],"python_abi":"cp312","abi":"json-v1"}
```

`entry.py`：

```python
def plugin_entry(request):
    if request["capability"] == "add":
        return request["params"]["a"] + request["params"]["b"]
    raise ValueError("未声明的能力")
```

目录选择 `plugin.json` 或把包根压成 ZIP 后加入。项目代码：

```python
print(plugins.call("sample.math", "add", {"a": 20, "b": 22}))
```

代理只在脚本 worker 中调用，遵循项目权限、宿主数、超时、输出限制和退出清理。当前 Node 不提供这个插件代理，使用 Python/中文源码桥接。

## 数据表

左侧程序夹分全局、窗口、程序集、局部变量、常量、自定义数据类型、DLL 命令。双击类别进入对应表，双击条目选择对应行。窗口/程序集变量补全使用 `所属代码名称.变量代码名称`。

“添加当前类别”打开完整属性表，填写名称、代码名称、规范中文类型、初始值、作用域、所属名称、数组维数和备注；局部变量可设置静态。数组例如 `3,4`，最多 10000 个元素。数据类型的“编辑成员/参数”支持成员数组；DLL 参数使用明确宽度 ABI 下拉框。表按类别显示相关列，非法值回滚，不会污染原数据。

## 子程序参数和局部变量

参数由调用方传入，在子程序内部使用；默认值只在省略对应参数时使用。局部变量由子程序自身创建，普通局部每次调用重新初始化；Python/中文源码的静态局部可以保留值。参数不能与显式局部声明重名。

代码表分开显示“参数（由调用方传入）”与“局部变量（子程序内部初始化）”。“编辑参数”按钮或 `Ctrl+Alt+P` 打开参数表，保存后改写真实源码签名；支持名称、类型、默认值、可省略及备注。Python 保留仅位置、仅关键字、`*args`、`**kwargs` 参数形式；复杂解构参数使用源码视图编辑。参数改名后须同步正文引用和所有调用处。

中文 `.参数` 未声明默认值时为必填参数；显式第三列默认值表示可省略，必填位置参数须在可省略参数之前。中文编译器版本提升为4以使旧构建缓存失效。Node 的省略参数、引用和类型行为遵循 JavaScript/TypeScript；Python 注解遵循 Python；没有伪造易语言的传址开关。源码 `.局部变量` 单独显示为只读表，可切换源码视图修改；编辑器添加的局部声明使用现有 `.pcide/routines.json` 合同。两者在 worker 中真实生效。

## 快捷键

帮助菜单 → **快捷键与操作说明**，或按 `F1`。

| 按键 | 操作 |
| --- | --- |
| Ctrl+N / Ctrl+O / Ctrl+S | 新建项目 / 打开项目 / 保存 |
| Ctrl+Shift+S | 当前文件另存为 |
| Ctrl+Alt+Shift+S / Ctrl+Alt+W | 项目另存为 / 关闭项目 |
| Ctrl+W | 关闭当前代码页 |
| Ctrl+Z / Ctrl+Y | 当前文本框、代码区或设计区撤销/重做 |
| Ctrl+F / Ctrl+H / Ctrl+G | 查找 / 查找替换 / 跳转行 |
| Ctrl+Space / Ctrl+Shift+F | 补全 / 格式化 |
| Ctrl+K / Ctrl+Alt+[ / Ctrl+Alt+] | 当前子程序收缩切换 / 全部收缩 / 全部展开 |
| Ctrl+Alt+P / Ctrl+Alt+V | 编辑当前参数 / 添加当前局部变量 |
| Ctrl+/ / Ctrl+E | 注释切换 / 设计与代码视图切换 |
| F5 / F4 / Shift+F5 | 运行 / 调试 / 停止 |
| F8 / F9 / F10 / F11 / Shift+F11 | 继续 / 断点 / 单步跳过 / 单步进入 / 单步跳出 |
| Ctrl+D / Delete | 在设计画布中复制 / 删除控件 |

设计画布的复制与删除使用局部快捷键作用域；文本字段拥有自己的撤销。收缩键切换真实子程序正文，恢复后显示正文。表格支持 Tab / Shift+Tab 移动，F2 或双击编辑。
